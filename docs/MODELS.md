# Parser Models – Data Structures

## Overview

Data models for the parser module using Python `dataclasses`. These structures ensure type safety and provide serialization methods for database persistence.

## Models

```
PageSchema         # Schema for domain
ParsedContent      # Extracted content
ExtractionResult   # Intermediate result
```

## PageSchema

Schema defining how to extract content from a specific domain.

### Structure

```python
@dataclass
class PageSchema:
    domain: str
    main_text_selectors: List[str]
    date_selector: Optional[str]
    is_valid: bool
    created_at: Optional[datetime] = None
    updated_at: Optional[datetime] = None
    id: Optional[str] = None
```

### Fields

| Field | Type | Description |
|-------|------|-------------|
| `domain` | `str` | Domain name (e.g., `"example.com"`) |
| `main_text_selectors` | `List[str]` | CSS selectors for content |
| `date_selector` | `Optional[str]` | CSS selector for date |
| `is_valid` | `bool` | Page relevance flag |
| `created_at` | `Optional[datetime]` | Creation timestamp |
| `updated_at` | `Optional[datetime]` | Update timestamp |
| `id` | `Optional[str]` | Database UUID |

### Methods

#### `to_dict()`

Convert to dictionary for database insertion.

```python
schema.to_dict()
```

**Returns:**
```python
{
    "domain": "example.com",
    "main_text_selectors": [".article p", ".content"],
    "date_selector": "time.published",
    "is_valid": True
}
```

**Note:** Excludes `id`, `created_at`, `updated_at` (auto-generated by database)

### Example

```python
schema = PageSchema(
    domain="earthquake.usgs.gov",
    main_text_selectors=[
        "article p",
        "div.content-text",
        ".description"
    ],
    date_selector="time.published",
    is_valid=True
)

# Save to database
data = schema.to_dict()
db.insert("page_schemas", [data])
```

### Database Mapping

**Table:** `page_schemas`

| Column | Type | Maps To |
|--------|------|---------|
| `id` | uuid | `schema.id` |
| `domain` | text | `schema.domain` |
| `main_text_selectors` | text[] | `schema.main_text_selectors` |
| `date_selector` | text | `schema.date_selector` |
| `is_valid` | boolean | `schema.is_valid` |
| `created_at` | timestamptz | `schema.created_at` |
| `updated_at` | timestamptz | `schema.updated_at` |

## ParsedContent

Extracted content from a webpage.

### Structure

```python
@dataclass
class ParsedContent:
    search_result_id: str
    main_text: List[str]
    date: Optional[str]
    page_schema_id: str
    parsed_at: Optional[datetime] = None
    id: Optional[str] = None
```

### Fields

| Field | Type | Description |
|-------|------|-------------|
| `search_result_id` | `str` | Foreign key to `search_results` |
| `main_text` | `List[str]` | Extracted paragraphs |
| `date` | `Optional[str]` | Publication date (ISO format) |
| `page_schema_id` | `str` | Foreign key to `page_schemas` |
| `parsed_at` | `Optional[datetime]` | Parsing timestamp |
| `id` | `Optional[str]` | Database UUID |

### Methods

#### `to_dict()`

Convert to dictionary for database insertion.

```python
content.to_dict()
```

**Returns:**
```python
{
    "search_result_id": "uuid-123",
    "main_text": ["Paragraph 1", "Paragraph 2"],
    "date": "2024-11-12",
    "page_schema_id": "uuid-456"
}
```

### Example

```python
content = ParsedContent(
    search_result_id="abc-123",
    main_text=[
        "Earthquake of magnitude 7.0 occurred today.",
        "The epicenter was located 50km north."
    ],
    date="2024-11-12",
    page_schema_id="def-456"
)

# Save to database
data = content.to_dict()
db.insert("parsed_content", [data])
```

### Database Mapping

**Table:** `parsed_content`

| Column | Type | Maps To |
|--------|------|---------|
| `id` | uuid | `content.id` |
| `search_result_id` | uuid | `content.search_result_id` |
| `main_text` | text[] | `content.main_text` |
| `date` | text | `content.date` |
| `page_schema_id` | uuid | `content.page_schema_id` |
| `parsed_at` | timestamptz | `content.parsed_at` |

## ExtractionResult

Intermediate result from HTML extraction (not persisted).

### Structure

```python
@dataclass
class ExtractionResult:
    main_text: List[str]
    date: Optional[str]
    success: bool
    error: Optional[str] = None
```

### Fields

| Field | Type | Description |
|-------|------|-------------|
| `main_text` | `List[str]` | Extracted paragraphs |
| `date` | `Optional[str]` | Publication date (ISO) |
| `success` | `bool` | Extraction success flag |
| `error` | `Optional[str]` | Error message if failed |

### Methods

None (no persistence needed)

### Example

```python
# Successful extraction
result = ExtractionResult(
    main_text=["Paragraph 1", "Paragraph 2"],
    date="2024-11-12",
    success=True
)

# Failed extraction
result = ExtractionResult(
    main_text=[],
    date=None,
    success=False,
    error="Invalid selector"
)
```

### Usage

```python
result = data_extractor.extract(html, schema)

if result.success:
    save_to_database(result.main_text, result.date)
else:
    print(f"Error: {result.error}")
```

## Type Safety Benefits

### 1. IDE Autocomplete

```python
schema = PageSchema(...)
schema.  # IDE suggests: domain, main_text_selectors, etc.
```

### 2. Type Checking

```python
schema = PageSchema(
    domain=123  # ❌ Type error: expected str
)
```

### 3. Required Fields

```python
schema = PageSchema()  # ❌ Error: missing required fields
```

### 4. Default Values

```python
content = ParsedContent(
    search_result_id="123",
    main_text=["text"],
    date=None,
    page_schema_id="456"
    # parsed_at and id auto-default to None
)
```

### Database Insert

## Validation

### Optional Fields

Fields with `Optional[T]` can be `None`:

```python
schema = PageSchema(
    domain="example.com",
    main_text_selectors=[".text"],
    date_selector=None,  # ✅ OK
    is_valid=True
)
```

### Required Fields

Fields without `Optional` must be provided:

```python
schema = PageSchema(
    domain="example.com",
    main_text_selectors=[".text"],
    # date_selector omitted - OK (Optional)
    # is_valid omitted - ❌ Error (required)
)
```

### List Types

```python
# ✅ Correct
main_text_selectors = [".selector1", ".selector2"]

# ❌ Wrong
main_text_selectors = ".selector1"  # Should be list
```

## Field Constraints

### PageSchema

| Field | Constraint |
|-------|------------|
| `domain` | Non-empty string, valid domain |
| `main_text_selectors` | Non-empty list of CSS selectors |
| `date_selector` | Valid CSS selector or None |
| `is_valid` | Boolean |

### ParsedContent

| Field | Constraint |
|-------|------------|
| `search_result_id` | Valid UUID string |
| `main_text` | List (can be empty) |
| `date` | ISO date string or None |
| `page_schema_id` | Valid UUID string |

## Common Patterns

### 1. Create → Validate → Save

```python
schema = PageSchema(
    domain=domain,
    main_text_selectors=selectors,
    date_selector=date_sel,
    is_valid=is_valid
)

if schema.is_valid:
    db.insert("page_schemas", [schema.to_dict()])
```

### 2. Load → Modify → Update

```python
schema = manager.get_by_domain("example.com")
schema.main_text_selectors.append(".new-class")
manager.save(schema)
```

### 3. Extract → Validate → Convert

```python
result = extractor.extract(html, schema)

if result.success:
    content = ParsedContent(
        search_result_id=search_id,
        main_text=result.main_text,
        date=result.date,
        page_schema_id=schema.id
    )
    db.insert("parsed_content", [content.to_dict()])
```
